# Outcome Labs RSS Featured Image

A WordPress plugin that adds the post featured image to the standard WordPress RSS feed.

## Description

This plugin adds the featured image for a post to the standard WordPress RSS feed.

## Requirements

- WordPress 6.0+
- PHP 8.0+

## Installation

1. Upload the `ol-rss-featured-image` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. No configuration is needed
